# Install the complete GitHub profile

Upload **all** the following to your public `samaelsimoes/samaelsimoes` repository (branch `main`):

- `README.md`
- `.github/workflows/profile-stats.yml`
- `scripts/generate_stats.py`

You do **not** need to upload the generated `assets/*.svg` files manually. They are generated by the workflow. For the first run, go to **Actions** → **Update GitHub profile statistics** → **Run workflow**. Wait for this run to finish and the SVGs will appear in `assets/` automatically, then refresh your GitHub profile. The workflow runs every day thereafter.

If the workflow has permission errors when pushing charts, go to **Settings → Actions → General → Workflow permissions** and enable **Read and write permissions** for the `GITHUB_TOKEN`. Organizational policies can override this setting.

**Important:** Annual and monthly commit numbers come from the official GitHub `contributionsCollection.totalCommitContributions` metric. This follows GitHub's contribution eligibility criteria, *not* every commit in every branch and every private employer repository. Private contributions are not automatically accessible to the workflow. The `active days` metric counts days with one or more contribution-calendar events, while `total contributions` may include commits, pull requests, issues and other events. Existing third-party widgets may have independent availability limitations.
