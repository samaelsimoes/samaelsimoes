# GitHub profile setup

The profile README and all displayed charts are in English.

The **Update GitHub profile charts** workflow generates SVG charts from the official GitHub GraphQL API daily and when the README, scripts, or workflow changes on main. You can also run it from the Actions tab with **Run workflow**.

No personal token or external chart service is required. The workflow uses GITHUB_TOKEN with contents: write permission. Repository or organization policies may restrict this permission.

Charts cover visible contributions. Private and corporate activity may be incomplete. The activity overview is a custom chart, and may differ from GitHub's native widget. The current calendar year is partial.
